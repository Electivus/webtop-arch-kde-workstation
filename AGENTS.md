# Agent instructions

## Agent skills

### Issue tracker

Before issue or pull request operations, read `docs/agents/issue-tracker.md`; the configured tracker is GitHub Issues in `manoelcalixto/webtop-arch-kde-workstation`.

### Triage labels

Before triage, read `docs/agents/triage-labels.md` for the five default role labels.

### Domain docs

Before exploring domain terminology or architecture, read `docs/agents/domain.md`; this repository uses a single context with root `CONTEXT.md` and `docs/adr/`.

### Planning context

Before planning across sessions or consuming a specification or ticket with a `## Planning context` marker, read `docs/agents/planning.md` and use `planning-context` to resolve the effort's decision ledger and validate its checkpoint.
